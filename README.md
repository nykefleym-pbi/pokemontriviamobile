# Pokémon Trivia Battle — Mobile

React Native / Expo rebuild of [pokemontrivia](https://github.com/nykefleym-pbi/pokemontrivia).

```
packages/core/        the deterministic battle engine (platform-free, 42 tests)
supabase/migrations/  the applied schema, dumped verbatim
docs/HANDOVER.md      start here
docs/ROADMAP.md       what is built and what is next
```

```sh
npm ci
npm run typecheck
npm test
```

`apps/mobile` (the Expo app) does not exist yet — see `docs/ROADMAP.md`.
